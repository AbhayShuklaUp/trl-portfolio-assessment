# TRL Portfolio Assessment

A standalone browser-based presentation dashboard for a three-project Technology Readiness Level portfolio assessment.

## Run locally

Open `index.html` in a modern browser. The app has no build step, external dependencies, or server requirement.

## Presentation controls

- Use the section tabs to move between the live dashboard, portfolio summary, project evidence, and TRL framework.
- Select **Present full screen** to enter presentation mode.
- Press `1` through `4` to switch sections; press `Esc` to exit full screen.

## Data note

Project facts and readiness levels reflect the supplied assessment presentation. The animated trend is illustrative browser-generated data, not live telemetry or additional project evidence.
